# 🐍 Snake Game

Полноценная игра "Змейка" с красивой графикой, анимациями, системой рекордов и звуковыми эффектами!

## ✨ Особенности

- 🎮 **Полноценный геймплей** - классическая змейка с современным интерфейсом
- 🎨 **Красивая графика** - анимированная змея с глазами, пульсирующая еда
- 🎵 **Звуковые эффекты** - процедурно генерируемые звуки
- 🏆 **Система рекордов** - сохранение топ-10 лучших результатов
- 📱 **Удобное меню** - главное меню, настройки, рекорды, титры
- ✨ **Анимации** - плавные переходы и эффекты частиц
- 🎯 **Простое управление** - стрелки или WASD
- 💻 **Кроссплатформенность** - работает на Windows, Mac, Linux

## 🚀 Быстрый старт

### Автоматическая установка (рекомендуется)

1. Скачайте проект
2. Запустите автоустановщик:
   ```bash
   python install.py
   ```
3. Следуйте инструкциям установщика
4. Играйте!

### Ручная установка

1. Установите зависимости:
   ```bash
   pip install pygame pyinstaller
   ```

2. Запустите игру:
   ```bash
   python main.py
   ```

## 🎯 Управление

- **Стрелки** или **WASD** - движение змеи
- **Space** - пауза/перезапуск игры
- **ESC** - возврат в главное меню
- **Мышь** - навигация по меню

## 📦 Создание исполняемого файла

Создайте exe-файл для распространения:

```bash
python build.py
```

Результат будет в папке `dist/`. Исполняемый файл включает все зависимости и может запускаться на любом совместимом компьютере без установки Python.

## 🏗️ Структура проекта

```
snake-game/
├── main.py              # Основной файл игры
├── install.py           # Автоустановщик
├── build.py            # Сборщик exe-файла
├── requirements.txt     # Зависимости
├── game/               # Игровые модули
│   ├── __init__.py
│   ├── config.py       # Настройки игры
│   ├── snake.py        # Логика змейки и игрового движка

│   ├── score_manager.py # Система рекордов
│   ├── sound_manager.py # Звуковые эффекты
│   └── input_dialog.py # Диалог ввода имени
├── assets/             # Ресурсы (иконки, звуки)
├── data/              # Сохранения и настройки
```

## 🎮 Геймплей

- Управляйте змеей, собирая красную еду
- За каждую еду получаете 10 очков
- Змея растет с каждой едой
- Избегайте столкновений со стенами и собственным телом
- Устанавливайте рекорды и соревнуйтесь с друзьями!

## 🔧 Технические детали

- **Язык**: Python 3.6+
- **Графика**: Pygame
- **Сборка**: PyInstaller
- **Звук**: Процедурная генерация через Pygame
- **Сохранения**: JSON файлы

## 🎨 Особенности реализации

### Анимации
- Плавное движение змеи с направленными глазами
- Пульсирующая анимация еды
- Система частиц для фона меню
- Плавные переходы между экранами

### Звуки
- Процедурно генерируемые звуковые эффекты
- Звук поедания еды (короткий бип)
- Звук окончания игры (нисходящий тон)
- Звуки навигации по меню

### Рекорды
- Автоматическое сохранение в JSON
- Топ-10 лучших результатов
- Ввод имени игрока при достижении рекорда
- Отображение даты и времени

## 🔄 Разработка

Для разработчиков:

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите игру: `python main.py`

### Добавление новых функций

- **Новые уровни**: модифицируйте `game/snake.py`
- **Звуки**: расширьте `game/sound_manager.py`
- **Визуальные эффекты**: добавьте в `game/menu.py`
- **Настройки**: обновите `game/config.py`

## 📋 Системные требования

- Python 3.6 или выше
- 100 МБ свободного места на диске
- Поддержка OpenGL (для Pygame)

## 🐛 Решение проблем

### Игра не запускается
- Убедитесь, что установлен Python 3.6+
- Запустите `python install.py` для проверки зависимостей

### Нет звука
- Проверьте аудиодрайверы системы
- Убедитесь, что pygame.mixer инициализировался правильно

### Низкая производительность
- Закройте другие приложения
- Игра оптимизирована для 60 FPS
